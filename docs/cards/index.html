The toggling game

  1. You may only tap a lit (white) vertex.
  2. Tapping it flips its neighbours: lit ↔ dark. The vertex you tapped stays lit.
  3. You win when exactly one vertex is lit. Fewest taps wins.
Taps: 0

Same as the card game from the talk: lit = face up, dark = face down. The two end vertices have only one neighbour, so tapping one flips just one vertex.
